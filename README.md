# rayhanshuvo.github.io

Personal portfolio site, served by GitHub Pages at https://rayhanshuvo.github.io

## Add a new project

1. Open `projects.js`.
2. Copy an existing `{ ... }` block and paste it at the top of the list.
3. Change the text. If the project has a chart or screenshot, upload it to `assets/` and set `image`.
4. Commit. The site updates in about a minute.

## Files

| File | What it is |
|---|---|
| `index.html` | The page itself |
| `style.css` | Colors, fonts, layout |
| `projects.js` | The list of projects (the only file you normally edit) |
| `assets/` | Images used by projects |
